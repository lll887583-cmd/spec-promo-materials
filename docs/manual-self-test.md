# Manual Self Test

Use this checklist when the user asks to self-test the promo materials tool, run a full manual check, or verify the complete export workflow.

## Goal

Verify that the tool can complete the full user workflow:

- Fill the required promo copy into the correct tool fields.
- Prepare copy for all 9 supported languages.
- Upload the local image named `黄金.png`.
- Save the current tool state.
- Download all generated assets to the local Desktop.
- Add the download date and time to the end of the downloaded file or folder name.

## Required Preview

- Start command: `npm run serve`
- Preview URL: `http://127.0.0.1:4173/`
- Before testing, confirm the page loads and there are no console errors.

## Manual Workflow

- [ ] Start or confirm the local preview service.
  - Run `npm run serve` from `/Users/macbookpro/Documents/New project/spec-promo-materials`.
  - Open `http://127.0.0.1:4173/`.

- [ ] Fill the English copy into the matching fields.
  - Title: `Trade Gold with Confidence`
  - Subtitle: `Low Spreads, High Liquidity, 24/5 Access`
  - CTA: `Start Trading`

- [ ] Fill all 9 languages with the table values.
  - The translations are prepared in this document, not generated by the tool.
  - Confirm every supported language has title, subtitle, and CTA copy.

- [ ] Upload the local image.
  - File name: `黄金.png`
  - First look in the current project and nearby user-provided paths.
  - If the file cannot be found, ask the user for the exact local path before continuing.

- [ ] Save the current configuration.
  - Use the tool's save action.
  - Verify the save state by refreshing or checking the tool's saved-state feedback.

- [ ] Download all generated assets.
  - Use the tool's "download all" or batch export action.
  - Save the result to the local Desktop.
  - Append the download date and time to the file or folder name.
  - Use timestamp format `YYYYMMDD-HHmm`, for example `promo-materials-20260519-1015`.

- [ ] Verify downloaded output.
  - Confirm the downloaded file or folder exists on the Desktop.
  - Confirm the name includes the timestamp.
  - Open or inspect at least these common sizes: 300x250, 300x600, 728x90, and 1200x1200.
  - Check that title, subtitle, CTA, logo, and the uploaded gold image render correctly.

## Required Report

After the self-test, report:

- Preview URL used.
- Source copy used.
- Image path used for `黄金.png`.
- Whether save succeeded.
- Desktop download location.
- Timestamped file or folder name.
- Sizes and languages checked.
- Any issues found.
- Suggested fix locations if issues are found.

## Formal Export Mandatory Rules

Before every full formal asset download, complete these checks:

- Use the local formal main image: `/Users/macbookpro/Desktop/黄金.png`.
- Do not use logos, placeholder images, or temporary test images as the main image.
- Fill all 9 official language copies from the table in this document before exporting.
- Do not export a formal package if any default placeholder copy remains:
  - `Headline Text`
  - `More information and key features here.`
  - `Button`
- Use “download all” and save the final ZIP to the desktop.
- After export, inspect the package:
  - Confirm there are 9 language folders.
  - Confirm each language folder contains 18 PNG files.
  - Spot-check at least English, 简体中文, and 日本語 files.
  - Confirm the main image is the gold image, not a logo or placeholder.
  - Confirm square sizes are ordered after large landscape sizes.
